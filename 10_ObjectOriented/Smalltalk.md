# Smalltalk

A linguagem Smalltalk é uma linguagem de programação exclusivamente orientada a objetos, diferente de outras linguagens que possuem suporte multiparadigma como Java e C++. 

Para fazer um Hello World em Smalltalk, você pode usar o seguinte código:

```st
'Hello World' printNl
```

Observe que a String antecede o método `printNl`, que imprime a string seguida de uma nova linha. Em Smalltalk, a sintaxe para passar uma mensagem para um objeto é:

```st
object message: arg1 arg2 ... argN
```
